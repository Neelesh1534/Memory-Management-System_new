Memory Management Fundamentals

In operating systems, Virtual Memory Management decouples logical process memory addresses from physical RAM address spaces using paged mapping tables, enabling execution of programs larger than physical memory.

1. Page Replacement Algorithms

  • FIFO (First-In, First-Out): Evicts the page that was loaded earliest into memory. Simple to implement using a queue, but subject to Belady's Anomaly.
  • LRU (Least Recently Used): Evicts the page that has not been accessed for the longest period of time. Uses stack or timestamp counter.
  • Optimal (OPT): Evicts the page that will not be used for the longest period in the future. Theoretical benchmark algorithm (requires future knowledge).
  • Clock / Second Chance: Approximates LRU using a circular buffer and a reference bit. If the bit is 1, it gets reset to 0 (second chance); if 0, the page is evicted.
  • LFU (Least Frequently Used): Evicts the page with the lowest reference frequency count.
  • MFU (Most Frequently Used): Evicts the page with the highest reference count based on the heuristic that high frequency pages have already served their purpose.

2. Dynamic Partitioning Allocation

  • First Fit: Allocates the process to the first free partition block large enough.
  • Best Fit: Allocates the process to the smallest partition block that is large enough, minimizing internal fragmentation.
  • Worst Fit: Allocates the process to the largest available partition block.
  • Next Fit: Variant of First Fit that begins searching from the location of the last allocation.
